# Stack Tecnológica

- **Backend:** Python, FastAPI e Uvicorn.
- **Banco de dados:** SQLite, com acesso pela biblioteca padrão `sqlite3`.
- **Frontend:** SPA em HTML, CSS e JavaScript, servida pelo FastAPI.
- **Gráficos e diagramas:** Plotly.js e SVG.
- **Autenticação:** sessões por cookie HTTP-only e senhas com hash bcrypt.
- **Testes de backend:** Pytest, FastAPI TestClient e HTTPX.
- **Verificações de frontend:** scripts Node.js com `assert` e `vm`, além de validação de sintaxe JavaScript.
- **Testes ponta a ponta (E2E):** Playwright Test com Microsoft Edge em modo headless e servidor FastAPI isolado.
- **Execução de QA:** scripts do `package.json`, com logs, JUnit e artefatos em `qa/evidencias/`; versões das dependências Node em `package-lock.json`.
